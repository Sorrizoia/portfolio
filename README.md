# Portfólio de Projetos

Projetos autorais de Inteligência Artificial aplicada, automação de processos, integração de sistemas e desenvolvimento de produtos digitais. Cada página apresenta o problema, as funcionalidades, a arquitetura, as tecnologias e o estágio atual da solução.

## Projetos

### [MultiSession](projects/multisession.md)

Aplicação desktop para Windows que reúne múltiplas contas e serviços em uma única interface, mantendo sessões locais isoladas. O projeto demonstra desenvolvimento de produto, arquitetura Electron, segurança de WebViews e IPC, testes automatizados e evolução assistida por IA.

### [Cannot Get](projects/cannot-get.md)

Bot de diversão e utilidade para WhatsApp, com criação de figurinhas, download de mídia, ferramentas criativas, recursos para grupos e mais de 5 mil usuários. O projeto utiliza Evolution API na operação principal e mantém uma integração OpenWA para automações em canais do WhatsApp.

### [Radar CNPJ](projects/radar-cnpj.md)

Aplicação web/PWA para consulta e acompanhamento de informações cadastrais de empresas e sócios. Integra APIs externas e automações n8n para pesquisa, alertas, favoritos, histórico e relatórios.

### [Automação de Notas Fiscais | Processamento Inteligente de Documentos](projects/automacao-notas-fiscais.md)

Automação inteligente para receber NFS-e por e-mail, validar anexos, extrair dados com IA, identificar duplicidades, organizar documentos e responder automaticamente ao remetente. O fluxo está em uso contínuo e integra n8n, Gmail, Google Drive, Google Sheets e um agente de IA.

Em evolução: suporte a documentos fiscais em XML e integração com API de OCR como fallback para PDFs sem camada de texto.
